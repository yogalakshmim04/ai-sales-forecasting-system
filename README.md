# AI-Based Sales Forecasting and E-Commerce Analytics System

MCA Mini Project

## Dataset
Place the UCI Online Retail dataset at:
`data/raw/Online Retail.xlsx`

## Main Modules
- Data preprocessing
- Exploratory data analysis
- Feature engineering
- Sales forecasting
- Model evaluation
- Customer segmentation
- Product analysis
- Demand analysis
- Business alerts
- Streamlit dashboard

## Run
Install dependencies:
`pip install -r requirements.txt`

Start the dashboard:
`streamlit run app/Home.py`
